# HTML5 Semantic Markup - Output Examples

This document shows the actual HTML output generated by the Stock Tracker application, demonstrating the implementation of HTML5 semantic elements and Schema.org microdata.

        type="button"

## Summary: Before vs. After

### Before (Plain HTML)
```html
<td>$185.50</td>
<td>2.35%</td>
```

**Machine reads**: "dollar sign one eight five point five zero" and "two point three five percent sign"

**SEO**: No structured data

**Accessibility**: Generic text

---

### After (HTML5 + Microdata)
```html
<td>
  <span itemscope itemtype="https://schema.org/MonetaryAmount">
    <data itemprop="value" value="185.50">$185.50</data>
    <meta itemprop="currency" content="USD">
  </span>
  <time datetime="2026-01-21T19:30:00.000Z" class="sr-only">
    2026-01-21T19:30:00.000Z
  </time>
</td>
<td>
  <data value="2.35">2.35%</data>
  <meter min="0" max="100" value="61.75" aria-label="Price change indicator: 2.35%"></meter>
</td>
```

**Machine reads**:
- Price: 185.50 USD (numeric value)
- Updated: 2026-01-21 at 19:30:00 UTC (ISO timestamp)
- Change: 2.35% (numeric value)
- Meter: 61.75/100 (gauge)

**SEO**:
- Rich snippets eligible
- Knowledge graph ready
- Voice search compatible

**Accessibility**:
- Screen reader announces: "Price: one hundred eighty-five dollars and fifty cents, last updated today at 2:30 PM"
- Meter announces: "Price change indicator: positive two point three five percent"
